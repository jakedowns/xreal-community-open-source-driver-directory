About ▸

USB Monitor — WebUSB Packet Inspector for XREAL Air glasses. Single-file HTML app using WebUSB, WebHID, and Three.js.

Captures and decodes IMU data from the glasses in real time: gyro (°/s), accelerometer (g), temperature (°C). Gyro sparkline and 3D head visualization.

IMU enable command (64B CRC32) sends via WebUSB or WebHID. Chrome blocks HID class interfaces on WebUSB ("protected class"), so the IMU enable works through WebHID sendReport on the MCU collection.

Connects to XREAL Air (vendor 0x3318). IF3 IMU data on EP 0x84.
